**Last Updated:** March 30, 2026 **App:** Field Scout **Vendor:** Numeric Oasis

## 1. Data We Collect

Field Scout does **not** collect, store, or persist any data on any server. The app operates entirely in real-time:

- **Field Metadata (Transient):** When you open Field Scout, it reads custom field metadata (field ID, name, description, type, screen count, context count, last-used date, and context configuration) via the Jira API to render the dashboard. This data is used solely for display and is never stored.
- **Project Metadata (Transient, On-Demand):** When you click "Load project data," Field Scout reads project names, keys, field configuration schemes, and issue type metadata to calculate per-project field counts and discover team-managed-only fields. This data is used solely for display and is never stored.

## 2. Personal Data Processing

Field Scout does **not** process any personal data. It reads only field configuration metadata and project configuration metadata, no user information, email addresses, issue content, or authentication tokens are accessed or processed.

## 3. Data Storage and Retention

- **Server-Side Storage:** None. Field Scout uses no databases, Forge storage, or server-side persistence of any kind.
- **Client-Side Storage:** None. No cookies, localStorage, or browser-side data is stored.
- **Data Deletion:** No stored data exists to delete. Uninstalling the app removes it completely.

## 4. Data Sharing

We do not share, sell, or transfer any data to third parties. All data remains within the Atlassian ecosystem. No external network calls are made.

## 5. Security

- Runs entirely on Atlassian Forge infrastructure (sandboxed).
- Read-only scopes, the app cannot modify, create, or delete any data.
- Accessible only to Jira site administrators.

## 6. GDPR Compliance

Since Field Scout stores no data of any kind on any server or in any browser, GDPR data subject rights are satisfied by design. All data shown in the dashboard comes directly from Jira's own API and is displayed transiently.
